# Python Day 5 – Creational Design Patterns

This folder covers all five classic creational design patterns:

1. Singleton
2. Factory Method / simple factory example
3. Builder
4. Prototype
5. Abstract Factory

## Run examples
From this folder:
- `python examples/singleton.py`
- `python examples/factory.py`
- `python examples/builder.py`
- `python examples/prototype.py`
- `python examples/abstract_factory.py`
- `python practice/practice.py`

Only the Python standard library is required.

Note: The `factory.py` example uses a beginner-friendly simple factory function to demonstrate object creation. The classic GoF Factory Method pattern is a more specific design involving creator classes and overridable factory methods.
